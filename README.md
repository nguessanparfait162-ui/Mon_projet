# Projet Web Design - Maquette Meubles

## Description
Intégration fidèle d'une maquette e-commerce (Desktop et Mobile) dans le cadre d'un projet de Web Design. Le site présente un catalogue de meubles avec filtres et une grille de produits.

## Technologies utilisées
- HTML5 (Structure sémantique, SEO)
- CSS3 (Variables, Flexbox, CSS Grid)
- Git / GitHub

## Fonctionnalités
- Interface Desktop fidèle à la maquette (3 colonnes).
- Interface Mobile responsive (1 colonne, adaptation des menus).
- Optimisation SEO (balises alt, title, meta description).
